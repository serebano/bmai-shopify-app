For authentication, offline token migration, Admin GraphQL, protected customer data, and webhook changes, navigate from the official Shopify documentation to the API/SDK version the repository actually uses. Verify SDK behavior against the installed package as well as its current docs. Keep public documentation separate from private reviewer feedback and live dashboard observations.
